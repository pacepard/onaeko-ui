# Introduction

`@onaeko/ui` is a framework-agnostic React component library used across Onaeko Web, App, Admin, and future products.

## What lives where

| Surface | Purpose |
| --- | --- |
| **Storybook** | Interactive component development, states, a11y checks |
| **Mintlify (this docs site)** | Installation, theming, tokens, integration guides |

Do not duplicate every Storybook example here. Link to Storybook for visual exploration.

## Package

```bash
pnpm add @onaeko/ui
```

```tsx
import { Button } from '@onaeko/ui';
import '@onaeko/ui/styles.css';
```
