# Installation

```bash
pnpm add @onaeko/ui
# or
npm install @onaeko/ui
```

## Peer dependencies

Required for the library:

```bash
pnpm add react react-dom
```

Also install when you use these surfaces:

| Peer | Needed for |
| --- | --- |
| `react-hook-form` | Form (`Form`, `FormField`, `FormControl`, …) |
| `react-is` | Chart / Recharts |

```bash
pnpm add react-hook-form react-is
```

Optional for validated Form stories and app schemas: `@hookform/resolvers` and `zod` (or another resolver-supported schema library).

## Styles

Import the package stylesheet once in your app root:

```tsx
import '@onaeko/ui/styles.css';
```

## Usage

```tsx
import { Button, Card, Input } from '@onaeko/ui';

export function Example() {
  return (
    <Card>
      <Input placeholder="Email" />
      <Button>Continue</Button>
    </Card>
  );
}
```

## Next.js

Use `transpilePackages: ['@onaeko/ui']` in `next.config` when needed. Only interactive components ship with `"use client"`.

## Vite

Install the package, import styles, and use components like any other React library.
