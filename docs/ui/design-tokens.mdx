# Design Tokens

Tokens are defined as CSS variables in `@onaeko/ui/styles.css` and mirrored in `src/tokens` for documentation.

Examples:

```css
--onaeko-background
--onaeko-foreground
--onaeko-primary
--onaeko-primary-foreground
--onaeko-secondary
--onaeko-muted
--onaeko-destructive
--onaeko-border
--onaeko-input
--onaeko-ring
```

Prefer semantic tokens over hard-coded colors in product code.
