# Package exports

`@onaeko/ui` is **ESM-only**. Use modern bundlers (Vite, Next.js, etc.). CommonJS `require()` is not supported.

## Entrypoints

| Import                     | Purpose                                                                                |
| -------------------------- | -------------------------------------------------------------------------------------- |
| `@onaeko/ui`             | Full component barrel                                                                  |
| `@onaeko/ui/styles.css`  | Compiled design tokens + component CSS                                                 |
| `@onaeko/ui/tokens`      | Typed token references (CSS variable strings)                                          |
| `@onaeko/ui/theme`       | `initTheme`, `setTheme`, helpers                                                       |
| `@onaeko/ui/<component>` | Per-component entry (kebab-case), e.g. `@onaeko/ui/button`, `@onaeko/ui/input-otp` |

```tsx
import { Button } from '@onaeko/ui/button';
import { tokens } from '@onaeko/ui/tokens';
import { initTheme } from '@onaeko/ui/theme';
import '@onaeko/ui/styles.css';
```

Subpath exports are generated by `pnpm sync:exports` (runs as part of `pnpm build`).

## Peers

| Peer                 | Required?                                   |
| -------------------- | ------------------------------------------- |
| `react`, `react-dom` | Always                                      |
| `react-hook-form`    | Optional — only when using Form             |
| `react-is`           | Optional — only when using Chart / Recharts |

## Icons & motion

- Icons: use [`lucide-react`](https://lucide.dev/) in apps (also used internally). There is no separate `@onaeko/icons` package yet.
- Motion durations/easing live on `tokens.motion` from `@onaeko/ui/tokens`.
