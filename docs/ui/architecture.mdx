# Architecture

## Primitive stack

Components wrap a mix of:

- **Radix UI** — most overlays and form primitives
- **Base UI** / **@shadcn/react** — selected newer surfaces
- **Libraries** — `sonner`, `vaul`, `cmdk`, `input-otp`, `react-day-picker`, `recharts`, `@dnd-kit/*`

Prefer Onaeko exports for styling and a11y conventions. Unifying on a single primitive vendor is an intentional future track, not a current requirement.

## Out of scope (for now)

- Automated Figma ↔ code sync (manual mapping documented in [Figma and icons](/ui/figma-icons))
- Full motion/choreography system beyond token durations
- Visual regression (Chromatic) until a project token is configured
- Auth, API clients, analytics, or product business logic

## Related packages

| Package         | Role                                         |
| --------------- | -------------------------------------------- |
| `@onaeko/ui`    | Components, tokens, theme, charts            |
| `@onaeko/icons` | Curated Lucide icon exports + `Icon` wrapper |
